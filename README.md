# Excel SUMIFS Revenue Analysis

## 📊 Project Overview

This project demonstrates how to use **Microsoft Excel's SUMIFS function** to calculate and analyze revenue based on multiple criteria.

The goal of this project is to show how Excel can be used to perform multi-criteria revenue analysis and extract meaningful business insights from sales data.

---

## 🎯 Objectives

- Calculate total revenue using the `SUMIFS` function.
- Analyze revenue based on multiple conditions.
- Understand how multiple criteria can be applied in Excel.
- Practice Excel data analysis techniques.
- Create a simple and practical revenue analysis project.

---

## 🛠️ Tools Used

- **Microsoft Excel**
- **SUMIFS Function**
- **Excel Formulas**
- **Data Analysis**

---

## 🧮 Excel SUMIFS Function

The `SUMIFS` function is used to calculate the sum of values that meet multiple criteria.

### Syntax

```excel
=SUMIFS(sum_range, criteria_range1, criteria1, [criteria_range2, criteria2], ...)
